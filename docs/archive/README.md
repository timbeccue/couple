# Archived plans

Completed implementation plans, moved here from the repo root to reduce clutter.
The work they describe has shipped — they are **historical**, not active.

They are kept (not deleted) because code comments across the repo cite them by name
as design rationale, e.g. `// PLAN-SPECTRAL-FINGERPRINT-MATCHING §13.4`. Deleting them
would orphan those references. The moves are pure `git` renames, and the comments
reference the plans by name (not path), so nothing breaks.

For *current* behavior, the authorities are `SPEC.md` / `SPEC-V2.md` /
`UX-DECISIONS.md` (and `PROGRESS.md` for the running log); active plans live in the
repo root.

- `PLAN-RMS-TIEBREAKER.md`
- `PLAN-MATCH-CLASSIFIER.md`
- `PLAN-AUDIO-MATCHING-PREWORK.md`
- `PLAN-SPECTRAL-FINGERPRINT-MATCHING.md`
