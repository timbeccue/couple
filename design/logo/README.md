# Couple logo assets

The mark is the wordmark's interlocked C+O: teal (camera) C, amber (external) O — the app's
two track colors from `mac/Sources/Couple/Theme.swift`. Over/under gaps are SVG mask cutouts,
so every file renders correctly on any background and stays crisp at any zoom.

## Final assets

- `couple-wordmark.svg` — full wordmark for dark surfaces. "UPLE" is outlined paths from
  **Nunito** (wght 875 — the weight whose stems match the 28-unit ring stroke; SIL Open
  Font License 1.1, font + license in `fonts/`), so no font is needed at render time and
  the wordmark can be used anywhere, on any platform. Generated by `outline-uple.py`.
- `couple-wordmark-light.svg` — the same wordmark with UPLE in the app's dark ink, for
  light surfaces. The repo `README.md` header shows it on GitHub's light theme and
  `couple-wordmark.svg` on the dark theme (an HTML `<picture>` with `prefers-color-scheme`
  sources). Generated alongside the dark file; never edit one without the other.
- `../../mac/Sources/Couple/Views/CoupleWordmarkGlyphs.swift` — the same UPLE outlines as a
  SwiftUI `Path`, generated by the same script. `CoupleWordmark` (in `CoupleMark.swift`)
  draws mark + glyphs natively in the queue rail header, so the app's lockup is identical
  to the SVG without bundling a font.
- `couple-appicon.svg` — app icon on the Apple icon grid (1024 canvas, 824 squircle,
  baked drop shadow). Source of the .icns.
- `Couple.icns` — generated from `couple-appicon.svg`; a copy ships from
  `mac/Resources/AppIcon.icns` (wired in `mac/Scripts/make-app.sh`).
- `fonts/Nunito[wght].ttf` + `fonts/OFL.txt` — the wordmark's typeface, pinned here so the
  outlines regenerate identically. Design-time only: nothing ships the font file, and the
  outlined glyphs in a logo are not "Font Software" under the OFL, so no runtime notice is
  needed. If a shell ever bundles the font itself, add it to `third-party/`.

### Why Nunito

The wordmark was first set in SF Rounded, whose license limits use to Apple-platform
contexts — a problem for the GitHub README and the Windows/Linux installers. On 2026-11-04
thirteen openly licensed rounded/geometric fonts were rendered as the lockup, weight-matched
to the ring stroke: Nunito is near-indistinguishable from SF Rounded; Fredoka and M PLUS
Rounded 1c were close; Quicksand, Comfortaa and Varela Round can't reach the stroke weight;
Rubik, Outfit, Figtree, Plus Jakarta Sans and Sen have square terminals that fight the round
mark; Baloo 2 runs too wide.

## Regenerating Couple.icns

Requires `rsvg-convert` (librsvg) and macOS `iconutil`:

```sh
cd design/logo
mkdir AppIcon.iconset
for s in 16 32 128 256 512; do
  rsvg-convert -w $s -h $s couple-appicon.svg -o AppIcon.iconset/icon_${s}x${s}.png
  rsvg-convert -w $((s*2)) -h $((s*2)) couple-appicon.svg -o AppIcon.iconset/icon_${s}x${s}@2x.png
done
iconutil -c icns AppIcon.iconset -o Couple.icns
cp Couple.icns ../../mac/Resources/AppIcon.icns
rm -rf AppIcon.iconset
```

## Regenerating the wordmark (SVGs + Swift glyphs)

`outline-uple.py` needs fontTools in a venv:

```sh
cd design/logo
python3 -m venv v && v/bin/pip install fonttools
v/bin/python outline-uple.py
```

It rewrites `couple-wordmark.svg`, `couple-wordmark-light.svg` and
`mac/Sources/Couple/Views/CoupleWordmarkGlyphs.swift` from `fonts/Nunito[wght].ttf`;
weight, cap height, baseline, start x and tracking are constants at the top of the script.
